# dshkol.com

Personal blog and portfolio site.

## Tech Stack

- [Astro](https://astro.build/) - Static site generator
- [TailwindCSS](https://tailwindcss.com/) - Styling
- [Pagefind](https://pagefind.app/) - Static search

Built on the [AstroPaper](https://github.com/satnaing/astro-paper) theme by [Sat Naing](https://satnaing.dev).

## Development

```bash
pnpm install
pnpm run dev
```

## Build

```bash
pnpm run build
```

Output is in `./dist/`.
