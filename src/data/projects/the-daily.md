The D-AI-LY is an experimental project that uses large language models to automatically generate readable statistical bulletins from Statistics Canada data releases.

## How it works

1. Monitors Statistics Canada for new data releases
2. Retrieves the underlying data using cansim
3. Uses LLMs to generate narrative summaries
4. Publishes bilingual (English/French) articles

## Features

- Automatic data retrieval and processing
- LLM-generated narrative summaries
- Bilingual output (English and French)
- Consistent formatting and structure
- Charts and visualizations
